# Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's
private vulnerability reporting or a GitHub security advisory for this
repository. Do not open a public issue or include credentials, personal data,
or an exploit that would expose live user data in a public discussion.

Include the affected revision, a concise reproduction, the impact, and any
suggested mitigation. Please allow time for confirmation and coordinated
disclosure. The public read APIs intentionally expose published designs,
matches, replays, and research experiments; reports should identify whether a
finding concerns that documented behavior or exposes private authentication,
deployment, or user data.
